# Task 3.2 Handoff — Curated hybrid retrieval

Implemented metadata-first PostgreSQL hybrid retrieval behind `CuratedKnowledgeRetriever`.
It filters to approved global/service/version-eligible chunks before lexical and pgvector
candidate search, applies fixed lexical/semantic admission before deterministic reciprocal-rank
fusion, and returns at most four complete passages within the 8,192-byte serialized batch limit.

`CuratedKnowledgeReferenceResolver` parses and resolves the fixed document/version and PDF
page-local or Markdown document-local reference grammar against retained historical chunks.
